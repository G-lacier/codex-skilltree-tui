# Profile a dataset

Inspect a sample to establish the delimiter, encoding, header, and quoting behavior. Report row and column counts, inferred types, representative values, and parse failures.

Distinguish missing markers from empty strings and numeric zero. Check duplicate records and inconsistent column counts. For time series, verify timestamp interpretation, ordering, duplicate timestamps, and gaps.

Document units and conversions from available evidence. Produce a compact profile that identifies data quality issues and any assumptions needed for further analysis.
